# Distributed Wagering Processor

Serviço que processa apostas de vários provedores de jogos, mantendo saldo e ledger corretos mesmo com mensagens duplicadas, fora de ordem e várias instâncias rodando ao mesmo tempo.

Em construção. O enunciado está em [docs/CHALLENGE.md](docs/CHALLENGE.md), a especificação em [docs/TECH_SPEC.md](docs/TECH_SPEC.md) e as decisões em [ARCHITECTURE.md](ARCHITECTURE.md).
